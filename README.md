# ScanExpress V1.0 — protótipo
Publique index.html na raiz do repositório e habilite GitHub Pages (branch main, /root). Abra a URL HTTPS no celular. Requer internet para carregar OCR, QR e XLSX de CDN. O OCR é heurístico: confira destinatário, endereço e rastreamento antes de confirmar. QR numérico é lido quando reconhecido; código de barras linear ainda não implementado. Impressão usa diálogo do navegador; ajuste dimensões e driver da impressora. Dados ficam no armazenamento local do navegador, não em servidor. Exporte XLSX antes de limpar dados. Não publique fotos de etiquetas reais no GitHub. Esta versão não foi testada em aparelho físico; não é versão comercial final.
